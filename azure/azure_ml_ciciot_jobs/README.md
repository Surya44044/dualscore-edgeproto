# Azure ML CICIoT2023 Experiment Job Templates

These job templates provide declarations for scaling model evaluation on the CICIoT2023 dataset using Azure Machine Learning.

## Phases
- **Phase 1 (2k samples)**: Fast verification run (`ciciot_phase1_2k.yml`).
- **Phase 2 (10k samples)**: Intermediate scaling study (`ciciot_phase2_10k.yml`).
- **Phase 3 (50k samples)**: Large-scale cross-dataset evaluation (`ciciot_phase3_50k.yml`).
