# Azure Deployment Manifests & Directory Overview

This directory contains template definitions, CLI deployment scripts, and runbooks for Azure cloud infrastructure.

---

## Subdirectories

- **`container_apps/`**: Azure Container Apps ARM/YAML template and deployment guide for the inference microservice.
- **`azure_ml_ciciot_jobs/`**: Azure Machine Learning job specifications for future scaled CICIoT2023 experiments.
- **`vm_runbook/`**: Runbook and guide for provisioning a Linux virtual machine for training operations.
